# A little room to think.

A quiet place for words, built with GPUI.

## Make something clear

Write **with emphasis**, find a little _rhythm_, and keep your thoughts close. Markdown takes shape as you type. There is no separate preview to manage.

- Start with one good sentence
- Give your ideas room to breathe
- Save them somewhere you can find them

> Simplicity is a matter of deciding what matters.

## Plain text. Yours to keep.

Open any UTF-8 Markdown file, make a change, and save it back. Your files stay plain Markdown.

```rust
let thought = "Something worth remembering.";
println!("{thought}");
```

A small editor, and a clean page.
